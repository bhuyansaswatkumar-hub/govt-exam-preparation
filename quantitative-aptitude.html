1. Number System

Number System is one of the most important topics for SSC and Banking examinations.

  • Natural Numbers: 1, 2, 3, 4...
  • Whole Numbers: 0, 1, 2, 3...
  • Integers: ..., -3, -2, -1, 0, 1, 2, 3...
  • Prime Numbers: Numbers having exactly two factors.
  • Composite Numbers: Numbers having more than two factors.
  • Even Numbers: Divisible by 2.
  • Odd Numbers: Not divisible by 2.
Important:
First Prime Number = 2
Smallest Composite Number = 4
Smallest Odd Prime Number = 3

2. Simplification

Use the BODMAS rule:

B = Brackets
O = Orders
D = Division
M = Multiplication
A = Addition
S = Subtraction

Always solve brackets first and multiplication/division before addition/subtraction.

3. Percentage

Percentage = (Part / Whole) × 100
Percentage Increase = (Increase / Original Value) × 100
Percentage Decrease = (Decrease / Original Value) × 100

Example: 20% of 500 = 100.

4. Profit and Loss

Profit = Selling Price − Cost Price
Loss = Cost Price − Selling Price
Profit % = (Profit / Cost Price) × 100
Loss % = (Loss / Cost Price) × 100
Selling Price = Cost Price + Profit
Selling Price = Cost Price − Loss

5. Simple Interest

SI = (P × R × T) / 100

Where:

  • P = Principal
  • R = Rate of Interest
  • T = Time
Amount = Principal + Simple Interest

6. Compound Interest

Amount = P(1 + R/100)T
Compound Interest = Amount − Principal

Compound interest is calculated on the principal plus previously accumulated interest.

7. Ratio and Proportion

Ratio = Comparison of two quantities

Example: If there are 2 boys and 3 girls:

Ratio of Boys : Girls = 2 : 3

If a : b = c : d, then:

a × d = b × c

8. Average

Average = Sum of Observations / Number of Observations

Example:

Numbers = 10, 20, 30

Average = 60 / 3 = 20

9. Time and Work

Work = Efficiency × Time

If a person completes a work in 10 days:

One day's work = 1/10

If A completes work in 10 days and B in 20 days:

A's work = 1/10
B's work = 1/20
Together = 1/10 + 1/20 = 3/20

10. Time, Speed and Distance

Distance = Speed × Time
Speed = Distance / Time
Time = Distance / Speed
1 km/hour = 5/18 m/sec
1 m/sec = 18/5 km/hour

11. Boats and Streams

Downstream Speed = Boat Speed + Stream Speed
Upstream Speed = Boat Speed − Stream Speed
Boat Speed = (Downstream + Upstream) / 2
Stream Speed = (Downstream − Upstream) / 2

12. Problems on Trains

When a train crosses a person:

Time = Length of Train / Speed

When a train crosses a platform:

Time = (Length of Train + Length of Platform) / Speed

13. Mixture and Alligation

Mixture questions involve combining two or more quantities having different prices or concentrations.

Mean Price = Total Cost / Total Quantity

Alligation is useful for finding the ratio in which two items should be mixed.

14. Partnership

Profit is divided according to investment × time.

Profit Ratio = Investment × Time

Example:

A invests ₹10,000 for 12 months and B invests ₹20,000 for 6 months.

A : B = 10000×12 : 20000×6
= 120000 : 120000
= 1 : 1

15. Mensuration

Rectangle

Area = Length × Breadth
Perimeter = 2(Length + Breadth)

Square

Area = Side²
Perimeter = 4 × Side

Triangle

Area = 1/2 × Base × Height

Circle

Area = πr²
Circumference = 2πr

16. Algebra

(a + b)² = a² + 2ab + b²
(a − b)² = a² − 2ab + b²
a² − b² = (a+b)(a−b)
(a+b)³ = a³ + b³ + 3ab(a+b)

17. Data Interpretation

Data Interpretation questions are based on tables, graphs, charts and percentages.

Always carefully check:

  • Total values
  • Percentages
  • Difference
  • Ratio
  • Average

18. Important Quantitative Aptitude Tips

  • Learn multiplication tables up to 20.
  • Remember squares from 1 to 30.
  • Remember cubes from 1 to 20.
  • Practice percentage conversions.
  • Learn important fraction-percentage equivalents.
  • Practice mental calculation.
  • Use approximation when appropriate.
  • Check units carefully.
  • Do not spend too much time on one question.
  • Practice previous-year questions regularly.
