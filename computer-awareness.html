Computer Awareness

Complete Notes for SSC, Banking & Competitive Exams

1. Computer Basics

Computer: An electronic device that accepts data, processes it and produces information.

  • Data = Raw facts and figures.
  • Information = Processed and meaningful data.
  • CPU = Central Processing Unit.
  • CPU is called the brain of the computer.
  • IPO = Input → Process → Output.

Main Functions of a Computer

  • Input
  • Processing
  • Output
  • Storage

2. Generations of Computers

Generation Period Main Technology
First 1940–1956 Vacuum Tubes
Second 1956–1963 Transistors
Third 1964–1971 Integrated Circuits
Fourth 1971–Present Microprocessors
Fifth Present & Future Artificial Intelligence

3. Hardware

Hardware refers to the physical parts of a computer that we can see and touch.

  • Monitor
  • Keyboard
  • Mouse
  • CPU
  • Printer
  • Scanner
  • Hard Disk
  • RAM
  • Motherboard

4. Software

Software is a set of programs or instructions used to operate a computer.

Types of Software

  • System Software: Operating system and system utilities.
  • Application Software: MS Word, Excel, Chrome etc.
  • Utility Software: Antivirus, backup and disk utilities.

5. CPU

CPU stands for Central Processing Unit.

Main Components

  • ALU – Arithmetic Logic Unit
  • CU – Control Unit
  • Registers

ALU: Performs arithmetic and logical operations.

CU: Controls and coordinates computer operations.

6. Memory

Primary Memory

  • RAM
  • ROM
  • Cache Memory

Secondary Memory

  • Hard Disk
  • SSD
  • Pen Drive
  • Memory Card
  • CD/DVD

RAM: Random Access Memory. It is volatile memory.

ROM: Read Only Memory. It is non-volatile memory.

1 Byte = 8 Bits

7. Operating System

An operating system manages computer hardware and software resources.

Examples

  • Windows
  • Linux
  • macOS
  • Android
  • iOS

Windows is developed by Microsoft.

13. Computer Networks

  • LAN: Local Area Network
  • MAN: Metropolitan Area Network
  • WAN: Wide Area Network
  • PAN: Personal Area Network

LAN covers a small geographical area.

WAN covers a large geographical area.

14. Cyber Security

Cyber security protects computers, networks and data from unauthorized access and attacks.

Common Threats

  • Virus
  • Worm
  • Trojan Horse
  • Spyware
  • Ransomware
  • Phishing
  • Hacking

Phishing: A fraudulent attempt to obtain sensitive information by pretending to be a trustworthy source.

15. Computer Viruses

A computer virus is a malicious program that can copy itself and affect computer files or operations.

Examples of Malware

  • Virus
  • Worm
  • Trojan
  • Spyware
  • Ransomware
